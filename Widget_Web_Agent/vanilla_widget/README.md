# Vanilla Widget

A standalone, framework-agnostic implementation of the chat widget using pure JavaScript. Designed for easy embedding into any HTML page.

## Files

- **`widget.js`**: The core logic and UI rendering. Contains all the JavaScript needed to run the widget.
- **`widget-embed.html`**: A minimal example showing how to embed the widget in a plain HTML file.

## Usage

1.  Include the `widget.js` script in your project.
2.  Add a container element (e.g., `<div id="widget-container"></div>`).
3.  Initialize the widget pointing to that container.

See `widget-embed.html` for a working code example.
