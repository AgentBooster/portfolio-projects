# MiniGame (Unreal Engine)

Playable demo built with Unreal Engine to explore basic mechanics, user input,
and project configuration. This directory contains the source project and its
main configuration.

## Goal

Test a simple gameplay loop and a clear technical base to iterate quickly:
input, character behavior, and engine configuration.

## Project contents

- `MiniGame.uproject`: project descriptor.
- `Source/`: C++ game code.
- `Config/`: engine, input, and editor settings.
- `Build/`: build resources for Mac (templates and entitlements).

## How to open

1. Open `MiniGame.uproject` with Unreal Engine.
2. Compile the project if needed.
3. Run Play mode to try the demo.

## Notes

- This demo is intended as an exploration base, not a final product.
- Configuration may vary depending on the Unreal Engine version.
- For local runs, a machine with a good GPU and proper cooling is recommended,
  since Unreal can be demanding and generate heat.
