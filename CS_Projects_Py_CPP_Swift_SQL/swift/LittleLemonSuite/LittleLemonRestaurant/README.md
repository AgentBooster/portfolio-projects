# Little Lemon Restaurant App

A modern, interactive iOS application designed to streamline the restaurant reservation experience. Built with **SwiftUI** and following the **MVVM** architectural pattern, this project demonstrates clean code practices, robust state management, and a polished user interface.

![Project Cover](Assets/ProjectCover.jpg)

## Overview

The Little Lemon app provides users with a seamless way to browse restaurant locations and manage reservations. It emphasizes clarity, responsiveness, and intuitive navigation, leveraging native iOS design components.

## Requirements

- **Xcode**: Version 13.0 or later.
- **iOS**: Target iOS 15.0 or later.
- **macOS**: macOS Monterey or later recommended for development.

## Getting Started

1.  Clone the repository.
2.  Open `LittleLemonRestaurant.xcodeproj` in Xcode.
3.  Select a simulator (e.g., iPhone 14 Pro).
4.  Build and Run (`Cmd + R`).

## Key Features

- **Interactive Locations Browser**: A dynamic list of restaurant branches with visual previews and detailed navigation logic.
- **Smart Reservation System**: An integrated booking form with validation logic, ensuring accurate party sizes and user inputs.
- **Robust State Management**: Utilizes `ObservableObject` and `@EnvironmentObject` to maintain consistent data state across different views and tabs.
- **Polished UI/UX**: Features custom assets, clean typography, and optimized layouts (including specific `List` styling and navigation bar handling).

## Technical Highlights

- **Framework**: SwiftUI (iOS 15+)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Language**: Swift 5
- **IDE**: Xcode 13+
- **Best Practices**:
  - Clean separation of concerns (Model vs. View).
  - Efficient list rendering and navigation state management.
  - Handling of view modifiers for visual consistency.
