Procedure/Description of Test:

I expanded the design by implementing a comparator and a BCD (Binary-Coded Decimal) converter. The logic evaluates the 4-bit input to check if it exceeds 9 (i.e., A-F in hex). If it does, the logic subtracts 10 from the input and asserts a carry bit to activate the tens digit on a second 7-segment display. This allows the system to display 4-bit binary inputs as true decimal numbers (0 to 15) instead of hexadecimal.

Observations:

For inputs between 0 and 9, the tens display remained off, and the units display accurately showed the input number. For inputs between 10 (1010) and 15 (1111), the tens display correctly showed a '1', while the units display correctly showed the remainder (0 through 5).

Questions:

  • Based on your observations of the board behavior once the FPGA is programmed, does it behave as you might expect?
    Yes, it successfully behaves as a true BCD converter. Numbers greater than 9 correctly trigger the second digit, providing an intuitive decimal readout of the binary switch values.

    It uses slightly less logic (8 Logic Elements compared to 14 in Part 1). This reduction occurs because Part 1 required a full 16-state decoding logic block.
