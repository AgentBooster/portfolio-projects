# CS Projects Portfolio (Py, C-Family, Swift, SQL)

This repository contains my consolidated CS project portfolio.
It is organized by language/domain for final projects and by track for weekly coursework.

## Structure

```text
CS_Projects_Py_CPP_Swift_SQL/
├── c-family/
├── python/
├── sql/
├── swift/
└── coursework_weeks/
```

## What each folder contains

- `c-family/`: C-family projects (C, C++, C#), organized by project name.
- `python/`: standalone Python projects.
- `sql/`: SQL-focused projects.
- `swift/`: Swift/iOS projects.
- `coursework_weeks/`: weekly exercises and problem sets grouped by CS50 track.

## Notes

- Project folders include their own `README.md` with setup and usage details.
- `coursework_weeks/` is intentionally kept lightweight as an archive of learning progress.
